# 对一个 agent 说话

一条完整的纵向:**挑一个 agent → 说一句话 → 看它回答 → 接着说 → 刷新还在**。

`02` 的终点是「找到了这台机器上装了什么」。这一片的终点是**它真的能用**。

**本文件不定布局。** 只写用户能做什么、被告知什么、失败时怎么办。

---

## 旅程

### ① 挑一个

Space 里能看到每台机器上有什么。挑一个在线的:

```
zane-mbp        Claude Code 2.1.231   ·   Codex 0.148.0
build-server-1  Codex 0.148.0
```

点开一个,就是一段对话。

### ② 说一句话

一个输入框。你打一句,发出去。

**它跑在那台机器上,在那个目录里。** 所以「读一下 src/payment 里的超时逻辑」是能办的事,不是它编的。

### ③ 它一个字一个字地回

不是转圈等它想完。它读了哪个文件、跑了什么命令,你都看得见:

```
读了 payment/timeout.ts
跑了 rg "timeout" src/
超时是 30 秒,写死在 client.ts:42,回调那条走的是另一个值……
```

**关掉浏览器它也在跑。** 回来接着看。

### ④ 接着说

它记得上一句。你不用重复上下文。

**记不住的时候会说出来** —— 见「接不上」。

### ⑤ 回来

刷新、换个设备、过一天回来,对话都在。

---

## 一段对话

```
在哪台机器上的哪个 agent      挑了就不能改。想换就是开一段新的
在哪个目录                    机器上的一个目录。对话里的每一句都在这儿
说过的话                      你说的和它说的,按顺序
```

**换 agent 就是开一段新对话。** 不做「把上下文搬过去」—— 那是在假装两个 agent 是同一个。

---

## 失败与恢复

**发一句话**

| 发生什么                    | 看到什么                       | 能做什么           |
| --------------------------- | ------------------------------ | ------------------ |
| 机器不在线                  | 这台机器现在不在线             | 等它回来 / 换一台  |
| 那个 agent 不在那台机器上了 | 这台机器上现在没有 Claude Code | 换一个 / 装回来    |
| 机器被移除了                | 这台机器不在这个 Space 里了    | 换一台             |
| 响应丢了                    | 不确定发出去没有               | 重试**不会说两遍** |

**它回答的过程中**

| 发生什么       | 看到什么                                        | 能做什么                         |
| -------------- | ----------------------------------------------- | -------------------------------- |
| agent 起不来   | 起不来,以及起不来的原因                         | 再说一遍                         |
| agent 中途死了 | 这一句没答完,以及它死在哪                       | 再说一遍                         |
| 机器掉线       | **不知道**它那边说到哪了                        | 不自动重发。你决定要不要再说一遍 |
| 接不上上一句   | **「它不记得前面说了什么,这一句是重新开始的」** | 不用做什么,但你知道它忘了        |
| 你把浏览器关了 | 它继续跑                                        | 回来接着看                       |

「不知道」和「死了」不能合并:后者再说一遍是安全的,前者可能让同一句话被处理两次。

**接不上是什么意思**

agent 自己记着上下文。那份记忆在它那台机器上,会过期、会因为机器重装而没。

接不上的时候我们**不假装接上了**。页面明说这一句是从头开始的。

## 承诺

```
① 你说的每一句话,只会被送到一个确定的 agent 上,不会串
② 它干的每件事你都看得见,不用它另外汇报
③ 关掉浏览器它照跑,回来什么都没少
④ 它不记得前面的时候会说出来,不冒充一段连续的记忆
⑤ 「不知道」永远不被猜成成功或失败,也不自动重发
⑥ 一段对话固定一个 agent,换 agent 就是换一段
```

## 完成标准

```
挑一个在线的 agent,说一句话,看着它一个字一个字回出来
它读文件、跑命令,过程都在页面上,不是只有结论
说第二句,它记得第一句
关掉浏览器,过一会儿回来 → 中间发生的都在,不重不漏
刷新页面 → 一样
换一台设备打开 → 一样
拔掉网线 → 那一句显示「不知道」,不自动重发
杀掉 agent 进程 → 说清楚它死了,再说一遍能继续
卸载 agent → 明确说这台机器上没有它了
机器离线 → 明确说,不是转圈
claude-code 和 codex 各走一遍完整旅程
```
