# 探索

这里放**还没有决定、也还没有建**的东西:调研过程,和调研得出的结论。

和 `roadmap/` 的区别只有一条,但很重要:

```
roadmap/    已经决定要做的一片。prd 是承诺,design 是怎么建
exploring/  还没排期的问题。写下来是为了不必重推一遍
```

**这里的每一句都不是承诺。** 读到一个结论,它的意思是「当时我们查完之后是这么想的」,不是
「我们会这么做」。真要做的时候,它进 `roadmap/`,并且要重新对着当时的代码检查一遍 —— 这里
引的产品和规范都在动。

每篇开头写清楚:回答的是哪个问题,查了什么,以及**哪些地方还没有答案**。
